# GAME-WATCHER-AUGUST-2024
-----------------------------------------------------------------------------
## What is this?
This is a RESTfull API Ajax application developed in JS React which served as a SoftUni React Course Exam Project. It is basically a website for gaming information and news.
-----------------------------------------------------------------------------
## How to run it locally?
-----------------------------------------------------------------------------
## 1. Clone repo
Open Command Prompt or VSC terminal, create a new folder, navigate to it in CMD/VSC:

"cd C:/<location>"

and clone repo on your machine:

"git clone https://github.com/S7lkr/game-watcher-august-2024"

## 2. Project setup
You will see 2 folders (client and server). Client is for FrontEnd, server for BackEnd. Navigate to server folder in terminal and type "node server" to start a local backend server. Open a new terminal and navigate to client/ folder. Type: "npm run preview" to start the backend.

### NOTE:
Notice that client and server (frontend and backend) are both on localhost but on different ports!
